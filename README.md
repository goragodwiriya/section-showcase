Web Sections Showcase
======

ภาพรวม
-------
โปรเจ็คนี้เป็นตัวอย่างหน้าเว็บแบบง่ายๆ สำหรับการแสดงตัวอย่าง (showcase) ของเนื้อหาหรือส่วนต่าง ๆ บนเว็บไซต์ โดยมีไฟล์หลักคือ [index.html](index.html) ซึ่งเป็นหน้าเดียวที่ใช้แสดงผล

วัตถุประสงค์
-----------
- แสดงตัวอย่างส่วนประกอบของหน้าเว็บ (layout / sections)
- คำอธิบายเกี่ยวกับ SEO, การแสดงตัวอย่างคอนเทนต์

วิธีใช้งาน
---------
1. เปิดไฟล์ `index.html` ในเบราว์เซอร์โดยตรง (ดับเบิลคลิกหรือใช้ `Open File`)
2. หรือวางโฟลเดอร์นี้ไว้บนเว็บเซิร์ฟเวอร์ (เช่น Apache, Nginx) แล้วเข้าผ่าน URL ที่ชี้มาที่โฟลเดอร์
